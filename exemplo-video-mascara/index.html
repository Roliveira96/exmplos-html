Método Rápido (Fundo Preto)

Mix Blend Mode

Se o vídeo tiver fundo preto puro, use mix-blend-mode: screen.

⚠️ Nota: Este método não funciona para o seu vídeo atual porque ele está com fundo verde. 

video {
  mix-blend-mode: screen;
}
Ouro (Fundo Verde/Chroma)

Remover Fundo Verde

Para transformar o fundo verde em transparência real, o comando FFmpeg abaixo aplica um filtro de chromakey e exporta em WebM.

ffmpeg -i input.mp4 -vf "chromakey=0x00FF00:0.1:0.2" -c:v libvpx-vp9 -crf 30 -b:v 0 -auto-alt-ref 0 -pix_fmt yuva420p output.webm

Por que está Verde?

O arquivo .mp4 foi exportado com fundo sólido (Chroma Key) porque o formato MP4 não suporta transparência nativa.

Solução: Converta para .webm usando o comando acima ou use ferramentas como Runway Gen-2 para exportar já com Alpha.
